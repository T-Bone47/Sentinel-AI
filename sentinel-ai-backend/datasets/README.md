# Demo datasets — fictional data

These 15 CSV files (14,400 rows) are **fictional demo data**. The repository
owner generated them with ChatGPT in 2026 to drive the Sentinel AI demo.

- **Everything in them is invented:** every name, email address, company,
  device, IP address, policy, log entry and score. None of it was collected
  from real people or organisations. Any resemblance to real people or
  companies is coincidental.
- **The email domain** is `meridianfintech.example`. The `.example` top-level
  domain is reserved (RFC 2606), so it cannot belong to anyone. It replaced a
  `.com` domain on 2026-11-18.
- **The IP addresses** are random routable addresses, not observed traffic.
- **No research result in this repository rests on these files.** The
  detection evaluations use seeded synthetic fixtures (`research/fixtures/`)
  and public datasets (`research/M2_REPORT.md`).

Full provenance review: `docs/DATA_PROVENANCE.md` at the repository root.
